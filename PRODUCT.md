# Product

## Register

product

## Users

Hack Club event hosts running YSWS (Ship Whatever Ships) events — mostly teenage/young-adult
hackathon organizers, technical but not designers. They post an RSVP link in Slack, then come back
to `/manage` to check in attendees, tweak event settings, and send Slack DM updates or feedback
requests. Sessions are short and task-driven: check a number, flip a toggle, send a message, get
out.

## Product Purpose

Let a host run the full lifecycle of an event RSVP: configure it, watch RSVPs/waitlist come in via
Slack, check attendees in at the door, message them, and collect feedback after — all from one
lightweight manage panel. Success is a host getting in, doing the one task they came for, and
leaving, without hunting for the right screen or button.

## Brand Personality

Fast, plain, no-nonsense. A utilitarian ops tool, not a showcase. Dense information over
decoration; get-in-get-out over guided tours.

## Anti-references

Generic AI-generated SaaS dashboard: card-soup layouts, identical icon+heading+text tiles
repeated everywhere, purple/gradient accents, hero-metric-with-gradient-text patterns, nested
cards, glassmorphism. If it looks like a template, it's wrong.

## Design Principles

- Density over decoration — this is a working tool used many times a day, not a landing page.
- One primary action per screen should be obvious at a glance; everything else recedes.
- Structure carries hierarchy (grouping, spacing, type weight) instead of boxing everything in cards.
- Slack is the real distribution channel — the web UI is a control panel, not the product's face.

## Accessibility & Inclusion

No specific requirements stated. Baseline: keyboard-operable controls, visible focus states,
sufficient contrast on the dark theme, no color-only status signaling.
